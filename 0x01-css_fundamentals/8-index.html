Theme Switcher

Dynamic CSS Variables

This layout uses CSS variables defined in :root for colors, spacing, and typography. No structural HTML changes are made when switching modes.

When the button above is clicked, the data-theme attribute on the root <html> element updates dynamically, triggering the [data-theme="dark"] selector to override the color variables smoothly.

Smooth Color Transitions

A transition property applied to background and text colors ensures that the visual change is seamless and comfortable for the eyes.
