

# CSS Foundations & Styling

## Module Description

Welcome to **0x01-css_fundamentals**, the second hands-on project in the **web_development** repository.

In the previous module (**0x00-html_fundamentals**), the focus was on creating the structure and content of web pages using HTML. This module introduces Cascading Style Sheets (CSS), allowing you to transform plain HTML into visually appealing, responsive, and user-friendly web pages.

Throughout this module, you will explore CSS fundamentals, including selectors, the box model, typography, colors, layouts with Flexbox and Grid, responsive design, CSS custom properties, and complete webpage styling.


## Learning Objectives

By the end of this module, you should be able to:

- Link external CSS files to HTML documents.
- Use CSS selectors effectively to target elements.
- Understand and apply the CSS Box Model.
- Style text using typography and font properties.
- Work with colors, gradients, backgrounds, and images.
- Create flexible layouts using Flexbox.
- Build advanced page layouts using CSS Grid.
- Implement responsive designs using media queries.
- Use CSS custom properties (variables) for maintainable styling.
- Build light and dark themes using CSS variables.
- Create modern, responsive, and professional-looking web pages.
- Validate CSS code using the W3C CSS Validator.

## Tasks Overview

| Task | Files | Description |
|--------|--------|-------------|
| 0 | `0-index.html`, `0-styles.css` | Set up and link an external CSS stylesheet. Implement a CSS reset, basic body styling, and style multiple HTML elements using element selectors. |
| 1 | `1-index.html`, `1-styles.css` | Demonstrate CSS selectors including element, class, ID, descendant, child, sibling, attribute, pseudo-class, and pseudo-element selectors. |
| 2 | `2-index.html`, `2-styles.css` | Build examples illustrating the CSS Box Model, including padding, borders, margins, box-sizing, shadows, and border-radius. |
| 3 | `3-index.html`, `3-styles.css` | Create a styled blog article showcasing typography concepts such as font stacks, spacing, alignment, decoration, and drop caps. |
| 4 | `4-index.html`, `4-styles.css` | Explore color systems, gradients, CSS variables, background images, and accessible contrast between light and dark sections. |
| 5 | `5-index.html`, `5-styles.css` | Create responsive Flexbox layouts, including navigation bars, hero sections, and card layouts. |
| 6 | `6-index.html`, `6-styles.css` | Build multiple CSS Grid layouts, including a gallery, holy grail layout, and magazine-style design. |
| 7 | `7-index.html`, `7-styles.css` | Design a fully responsive portfolio page using media queries, fluid typography, responsive images, and adaptive layouts. |
| 8 | `8-index.html`, `8-styles.css` | Implement light and dark themes using CSS custom properties and theme switching with JavaScript. |
| 9 | `9-index.html`, `9-styles.css` | Create a fully styled professional webpage featuring navigation, hero section, cards, tables, forms, media, and responsive design principles. |


## How to View the Files in a Browser

### Option 1: Open Directly

1. Navigate to the project directory.
2. Locate the desired HTML file (for example, `0-index.html`).
3. Double-click the file, or right-click and select **Open With**.
4. Choose your preferred web browser.
5. Verify that the corresponding CSS file is loaded correctly.

### Option 2: Use VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click the desired HTML file.
4. Select **Open with Live Server**.
5. The page will automatically open in your browser and refresh when changes are saved.
