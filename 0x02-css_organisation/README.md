CSS Organization Project:

About the Project:
This project demonstrates how to organize CSS files in a scalable and maintainable way. Instead of writing all styles in one file, the CSS is divided into separate files based on their purpose, making the code easier to manage and understand.

Folder Structure:

├── README.md
└── css/
    ├── reset.css
    ├── variables.css

    └── components/
        ├── button.css

        ├── form.css
        ├── header.css
        └── footer.css
What Each CSS File Does:
reset.css-
Removes default browser styles to ensure consistency across different browsers.

variables.css-
Stores reusable CSS variables such as colors, font sizes, spacing, and other design values.

base.css-
Contains global styles for elements like the body, headings, paragraphs, and links.

layout.css-
Defines the overall page layout, including containers, sections, and positioning.

main.css-
Imports and connects all CSS files, serving as the main stylesheet for the project.

components/button.css-
Styles all button components and their different states.

components/card.css-
Defines the appearance of card components.

components/form.css-
Provides styling for form elements such as inputs, labels, and text areas.

components/header.css-
Contains styles for the page header and navigation elements.

components/footer.css-
Contains styles for the page footer.
