# 0x00. HTML Fundamentals

This module covers the foundational building blocks of web development — semantic HTML markup.

## Learning Objectives

- Understand HTML5 document structure and meta tags
- Use semantic elements for meaning and accessibility
- Create accessible forms with proper labels
- Build semantic tables with proper headers
- Embed media (images, video, audio) accessibly
- Structure content with headings, paragraphs, and lists
