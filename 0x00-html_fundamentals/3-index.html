Key Web Development Terms

HTML
The standard markup language for creating web pages.
CSS
A stylesheet language used to describe the presentation of a document written in HTML.
JavaScript
A programming language that enables interactive web pages and dynamic content.
Responsive Design
An approach to web design that ensures pages render well on a variety of devices and screen sizes.
SEO
Search Engine Optimization, the practice of improving a website’s visibility in search engines.
